Touhou Little Maid for **Minecraft 26.2** (Java Edition, NeoForge): an unofficial continuation of
[Touhou Little Maid](https://github.com/TartaricAcid/TouhouLittleMaid) by TartaricAcid.

## How to install

1. Install **[NeoForge](https://neoforged.net/) 26.2.0.90** (or newer 26.2.x) for Minecraft 26.2.
   - Official launcher: download the NeoForge installer, run it, choose "Install client".
   - CurseForge / Modrinth / Prism / other launchers: create a **Minecraft 26.2 + NeoForge** profile.
2. Put the downloaded `touhoulittlemaid-….jar` into that profile's **`mods`** folder.
   Remove any older copy of this mod first.
3. Start the game with the NeoForge profile. You'll find everything in the **Touhou Little Maid** creative tab.

That's it. It's one mod file and needs no other mods.

## Status

🧪 **Alpha.** The mod loads and runs, but it's new on 26.2, so expect bugs.
- Use a **new world** or **back up your worlds** first.
- Integrations with other mods (JEI, Jade, Curios, …) and the Patchouli guide book are off until those mods support 26.2.

## Found a bug?

[Open an issue](https://github.com/neerajdad123-byte/little-maid-continued/issues) and attach:
- `logs/latest.log` from your game folder
- any file in `crash-reports/` (if the game crashed)

## Building from source

Requires JDK 25.

```
./gradlew build
```

The mod jar is written to `build/libs/`.
