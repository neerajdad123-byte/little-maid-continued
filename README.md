# Little Maid Continued

An unofficial, community port of [Touhou Little Maid](https://github.com/TartaricAcid/TouhouLittleMaid) by TartaricAcid to newer Minecraft versions.

> This project is not affiliated with or endorsed by the original author.
> Please support the original mod on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/touhou-little-maid).

## Goals

- Port the latest upstream release (NeoForge, MC 1.21.1) to newer Minecraft versions
- Keep save compatibility where possible
- Fix bugs and add small quality-of-life improvements
